🐞 本页 Bug 清单 对照源码找出下述 4 处问题

BUG #1 · 滑块绑定错位
"重力 g" 滑块实际改变了初始角 θ₀
现象：你拖动 g 滑块时，初始角 θ₀ 跟着变；真·重力 g 反而没动。
→ 观察右上角 HUD "θ₀ 初始角" 这一行的数值。
💡 提示：bindRange(...) 的第三个参数（key）写错了
BUG #2 · 物理公式错误
阻尼被加到了角频率 ω 上，摆动反而变快
现象：增大"阻尼 γ"后球摆得更快，而不是慢慢衰减。
→ 观察 HUD "实测 ω vs 理论 ω" 的差异。
💡 提示：阻尼应当乘在指数项 e-γt，而不是和 ω 相加
BUG #3 · 重置函数不完整
"重置摆动"按钮没把 θ₀ 重置回 45°
现象：先拖 g 滑块改变 θ₀（Bug#1 的副作用），再点"重置摆动"——球会从上一次的 θ₀ 重新释放，而不是 45°。
💡 提示：resetSwing() 漏了一行
BUG #4 · 轨迹颜色错位
运动轨迹整条一个颜色，没有渐变
现象：球的轨迹线整条都是同一个不透明的颜色，没有"新→旧"的渐隐效果。
💡 提示：drawTrail() 里循环变量 i 没被用上

📄 源码（带 Bug 标记）

const physics = {
  L: 200, g: 9.8,
  theta0: 45 * Math.PI / 180,
  damping: 0
};

function theta(t) {
// 🐛 BUG #2 阻尼加到了频率而非指数
  return physics.theta0 * Math.cos((omega() + physics.damping) * t);
}

function drawTrail() {
// 🐛 BUG #4 颜色没用渐变
  for (let i = 1; i < trail.length; i++) {
    ctx.strokeStyle = `rgba(127, 200, 255, 0.35)`;
    ctx.lineWidth = 1.5;
    // ❌ 缺少 a = i / trail.length 的渐变计算
  }
}

function resetSwing() {
// 🐛 BUG #3 漏了一行：physics.theta0 = π/4
  t = 0;
  trail = [];
  lastT = performance.now();
}

// 滑块绑定
// 🐛 BUG #1 第三个参数应是 'g' 不是 'theta0'
bindRange('rG', 'valG', 'theta0', v => v.toFixed(1));
BUG #1：把 bindRange('rG', 'valG', 'theta0', ...) 改为 bindRange('rG', 'valG', 'g', ...)。
BUG #2：把 Math.cos((omega() + damping) * t) 改为 Math.cos(omega() * t) * Math.exp(-damping * t)。
BUG #3：在 resetSwing() 开头加一行 physics.theta0 = 45 * Math.PI / 180;。
BUG #4：在循环里加 const a = i / trail.length; 并把颜色改为 rgba(127,200,255,${a*0.35})、线宽改为 1.5 * a。
